# OfficeAgent

Универсальный self-hosted харнес для персонального AI-агента поверх
**Claude Code** — Telegram-бот, который живёт на твоём собственном сервере,
под твоим собственным Telegram-ботом, и говорит с твоим собственным
аккаунтом Claude. Никаких чужих данных, никакого чужого сервера.

Просто, без лишней инфраструктуры: два сервиса на systemd + одна база
Postgres в Docker. Никакого docker-compose стека на десяток контейнеров.

## Что умеет

- **Личка в Telegram** — пишешь боту, он отвечает через живую `claude`-сессию
  на сервере (полный набор инструментов: файлы, bash, MCP).
- **Супергруппы и топики** — параллельные независимые сессии на каждый чат,
  с собственной памятью и permission-gate.
- **Подтверждение опасных действий кнопками** — bash-паттерны, которые ты сам
  считаешь рискованными (`git push --force`, `rm -rf` и т.п.), уходят в
  Telegram как Allow/Deny, а не выполняются молча.
- **`/model` — переключение модели на лету** — без потери контекста
  (`--continue`/`--resume`) можно прыгать между основным провайдером
  (Anthropic) и альтернативным (см. ниже), прямо из Telegram.
- **Голосовые сообщения** — транскрипция через Groq Whisper (опционально).
- **gbrain** — общая память/recall/swarm/task как MCP-инструменты, чтобы
  агент помнил решения между сессиями, а не начинал с чистого листа каждый раз.

## GLM (Z.ai) как основной провайдер — без риска для Claude-аккаунта

Отдельная фича, ради которой стоит обратить внимание: агент можно поднять
**вообще без единого Anthropic-креда** — только с токеном GLM (Z.ai),
Anthropic-совместимым API. Всё работает: личка, группы, permission-gate,
`/model`. Если позже захочешь добавить свой Anthropic-ключ или подписку —
`/model` даст переключаться между GLM и Claude на лету, не теряя историю
разговора.

Смысл: автоматизированные headless-сессии (много параллельных чатов,
круглосуточная работа) — это нагрузка, которую не хочется вешать на личный
Claude-аккаунт с риском словить лимиты или бан за нетипичное использование.
GLM — отдельный API-провайдер именно под такую нагрузку, поэтому его можно
безопасно сделать основным, а Claude-подписку/ключ подключить отдельно —
или не подключать вообще.

## Установка — одна команда

```bash
git clone https://github.com/a-prs/OfficeAgent.git && cd OfficeAgent && sudo bash install.sh
```

Установщик сам поставит зависимости (Node, Python, Docker, tmux), спросит
несколько вопросов (см. ниже) и поднимет всё под systemd.

## Какие ключи нужны

| Ключ | Обязателен? | Где взять |
|---|---|---|
| **Telegram bot token** | да | [@BotFather](https://t.me/BotFather) |
| **Твой Telegram user id** | да | [@userinfobot](https://t.me/userinfobot) |
| **ANTHROPIC_API_KEY** или **CLAUDE_CODE_OAUTH_TOKEN** | нет, если используешь GLM как основной | console.anthropic.com / логин Claude Code по подписке |
| **GLM (Z.ai) токен** | нет, если используешь Anthropic как основной | z.ai — токен для Anthropic-совместимого API |
| **Groq API key** | нет — только для голосовых сообщений | console.groq.com |

Нужен хотя бы один способ авторизации Claude Code (Anthropic-ключ/подписка
**или** GLM-токен) — установщик не даст поставить систему совсем без модели.
Полный список переменных с комментариями — `env.example`.

## Архитектура

Postgres+pgvector — единственное, что крутится в Docker
(`docker-compose.yml`, сервис `db`) — ради воспроизводимого образа.
`bot/` (Telegram-роутер, TypeScript/bun) и `gbrain/` (память/recall/swarm/
task, Python) — обычные процессы под systemd
(`systemd/officeagent-{db,gbrain,bot}.service`), каждый под своим
непривилегированным системным пользователем (`officeagent`, без sudo).

```
bot/                  Telegram-бот + роутер сессий (TypeScript, bun)
gbrain/                память/recall/swarm/task MCP-сервисы (Python)
templates/              шаблоны workspace/vault для новой установки
systemd/                 officeagent-{db,gbrain,bot}.service
docker-compose.yml       только Postgres+pgvector
install.sh               установка зависимостей, systemd-юниты
env.example              справочник по каждому значению конфига
```

## Статус

Прогнан живьём end-to-end (личка + супергруппы/топики + `/model`
переключение GLM↔Claude) на чистом VPS, полный цикл wipe+install
проверялся многократно. `bot/src/**` типизируется без ошибок. Часть
юнит-тестов (`bot/tests/**`) ещё содержит фикстуры под старые названия
полей — рантайм это не затрагивает, чистка в процессе.
